# 📚 Bookmarker

A simple and responsive web application that allows users to save, manage, and visit their favorite websites. The project uses **Local Storage** to keep bookmarks even after refreshing or closing the browser.

## ✨ Features

* Add a new bookmark.
* Validate site name and website URL.
* Store bookmarks using Local Storage.
* Visit saved websites with one click.
* Delete bookmarks.
* Responsive user interface.
* User-friendly validation modal.

## 📖 How It Works

1. Enter the website name.
2. Enter the website URL.
3. Click **Submit**.
4. The bookmark is saved in Local Storage.
5. Click **Visit** to open the website.
6. Click **Delete** to remove it.

---

## ✅ Validation Rules

* Site name must contain at least **3 characters**.
* Website URL must be a valid URL.
* Invalid input displays a warning modal.
